Un bull's eye est une catégorielle répétée sur chaque segment
Le type fixe le découpage, le jeu de valeurs fixe les réponses possibles. Une lecture produit donc 17 réponses catégorielles, comparées segment par segment. Changer le jeu de valeurs ici ne touche aucun bloc : chacun garde la copie prise à l'import.
